# 🌐 EagleEye  

EagleEye is an AI-powered computer vision project built to explore **object detection** and advanced deep learning models.  
It uses **TensorFlow/Keras** for training and testing, with large model files managed via **Git LFS**.  

---

## ✨ Features  
- 🚀 Object detection with deep learning  
- 🗂️ Organized datasets for training and testing  
- 📦 Support for large models through Git LFS  
- 🔧 Easy setup and extension
